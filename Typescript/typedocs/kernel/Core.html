Kernel Core ​

How a write in this.me reaches only the values that depend on it. Every link and number on this page is this.me 4.2.1 (tag v4.2.1; the npm 4.2.1 dist is built from the same src).

Concept first: O(k) · me.explain(path) · Extreme Fan-Out. How a call becomes a path: Proxy calls.

Cost model ​

k is the number of derived values one write recomputes; n is everything else in the tree. A write costs O(k), and explain(path).meta.k reports k for the last wave.

Inverted index ​

On ["="] the kernel extracts the formula's references and records source path → [target paths] in refSubscribers. A write to a source walks only that entry:

txt
write(source) → invalidateFromPaths([source])
              → refSubscribers[source] → targets
              → eager: recomputeTarget(target), then its own subscribers
              → lazy:  mark stale; ensureTargetFresh(target) on read

recomputeTarget returns whether the value changed. Dependents of an unchanged value are not recomputed (early cutoff, explain().meta.changed).

Measured on 4.2.1 ​

1,200 trucks, one [i] formula, eager mode (default). Run with node on npm this.me 4.2.1; box: Intel Xeon, 8 vCPU, Node v20.19.2, 2026-10-14, p50 of 30.

ts
import ME from "this.me";
const me = new ME();
me.finance.fuel_price(24.5);
for (let i = 1; i <= 1200; i++) me.fleet.trucks[i].fuel(100 + (i % 50));
me.fleet["trucks[i]"]["="]("cost", "fuel * finance.fuel_price");

me.finance.fuel_price(99);
me.explain("fleet.trucks.600.cost").meta.k; // 1200
me.fleet.trucks[600].fuel(1);
me.explain("fleet.trucks.600.cost").meta.k; // 1
me("fleet.trucks.600.cost");               // 99

Evaluator ​

Formulas run in a small evaluator, not eval or new Function: tokenize, precedence (shunting-yard) to RPN, evaluate. Source: tokenizeEvalExpression L47–151, compileUncached L228–322, tryEvaluateAssignExpression L324–429. Details and outputs: Intelligence.

explain() and secrets ​

explain(path) (derivation.ts L140–251) returns the expression, every input with its path, origin and status, and meta (dependsOn, k, recomputed, changed). Inputs read from a secret branch are returned as ●●●● with masked: true (L214–215). Example output: Intelligence.

Snapshots ​

exportSnapshot L44–57 emits the memory log and the secret planes (localSecrets, localNoises, encryptedBranches, keySpaces, …). hydrate L73–111 rebuilds from them and resets derivations (L95). Values come back; live formulas do not (see Intelligence).

Guarantees and limits in 4.2.1 ​

  • Memories. Every write is appended to the memory log (Memory).
  • Cycles. a = b + 1, b = a + 1 does not overflow: both values are undefined and explain().meta.unresolved is { reason: "cycle", cycle: [...] }.
  • Cleanup. Redefining a target (L584) or removing a subtree (clearDerivationsByPrefix L1052–1066) calls unregisterDerivation, which drops its subscriptions.
  • Log growth. Recomputed values are appended too, so a long eager stream grows the log (#5).
